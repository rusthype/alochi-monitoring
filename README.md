# Alochi Monitoring

O'zbekistondagi maktablar uchun test tizimi monitoringi dasturi (Windows).

## O'rnatish

### Tavsiya qilingan usul: Setup.exe

1. [Eng so'nggi versiyani yuklab oling](https://github.com/rusthype/alochi-monitoring/releases/latest) — `AlochiMonitoring-*.exe` faylni izlang
2. Faylni ikki marta bosib o'rnatishni boshlang
3. Kerakli papkani tanlang va **Install** bosing
4. Desktop'dagi yorlig'i orqali dasturni ishga tushiring

**Batafsil yo'riqnoma:** [O'rnatish qo'llanmasi](docs/INSTALL.md)

### Portable o'rnatish

Zip archivini ochib `alochi_monitoring.exe` ni ishga tushiring:

```powershell
# Zip ni yuklab oling va ochib qo'ying
# alochi_monitoring.exe ni ishga tushiring
```

### Ilg'or: PowerShell skripti

Agar PowerShell'da avtomatik o'rnatish istasangiz:

```powershell
# Admin PowerShell'da ishga tushiring:
iex (irm https://raw.githubusercontent.com/rusthype/alochi-monitoring/main/install.ps1)
```

> **Eslatma:** Setup.exe usuli ta'minot qilingan va xavfsiz bo'lgani uchun tavsiya qilinadi.
